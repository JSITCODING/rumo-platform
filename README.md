# Rumo Platform

Repositório do projeto Rumo Platform. Nesta fase, o repositório reúne a base
documental usada para alinhar produto, escopo, fluxos, decisões, dados e
qualidade antes do início da implementação.

Os requisitos e as decisões ainda não validados estão assinalados como
**Por definir**. A documentação não deve ser interpretada como autorização
para ampliar o escopo ou iniciar desenvolvimento sem aprovação.
