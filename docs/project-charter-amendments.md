## A1 — Fonte canónica de design

- **Estado:** Aprovada
- **Data:** 8 de agosto de 2026
- **Decisão relacionada:** P7
- **Issue:** #14

### Regra original

> Figma é a fonte de verdade para design.

### Regra substituta

> Penpot Cloud é a fonte canónica de design activo. O Figma é arquivo histórico e não deve receber novas alterações. O GitHub continua a ser a fonte canónica para decisões, documentação, tokens, checkpoints e código.

### Motivo

As restrições de chamadas e colaboração do fluxo anterior impediam a continuidade previsível do trabalho. O Penpot oferece um percurso aberto e exportável para wireframes, foundations, componentes e protótipos, mantendo a opção de autoalojamento futuro.

### Aplicação

- criar o projecto `Rumo — MVP` e o ficheiro `Rumo — Product Design`;
- migrar os oito wireframes móveis aprovados como referências bloqueadas;
- criar todas as novas foundations, componentes, telas e ligações de protótipo no Penpot;
- guardar tokens e o manifest de checkpoints no GitHub;
- anexar cada exportação `.penpot` aprovada a uma GitHub Release;
- não eliminar os ficheiros históricos do Figma;
- não iniciar frontend ou backend de produção antes da aprovação do design visual, protótipo e testes.

### Revisão

Rever apenas se o Penpot Cloud deixar de ser operacional, se for aprovado o autoalojamento ou se outra decisão formal substituir P7.
