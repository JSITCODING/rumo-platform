# Identidade Rumo

## Ideia central

O percurso transforma incerteza em direção sem fingir certeza. A identidade deve continuar reconhecível pela origem em Luanda, linha de rota, marcadores de evidência e ritmo editorial antes de o nome aparecer.

## Uso

- Papel quente `#f5f0e7`, tinta `#14251f` e Atlântico `#2755c7` são a base.
- Terracota `#b95332` identifica apenas origem e orientação.
- Newsreader orienta títulos; Manrope serve interface e leitura.
- Manter pelo menos metade da altura do símbolo como espaço livre.
- Não esticar, inclinar, aplicar gradientes ou substituir a rota por ícones genéricos de educação.

O ficheiro `rumo-social-preview.svg` é o original de repositório. A configuração social do GitHub deve usar a sua versão PNG de `1280 × 640`.
